# VM Trans 窗口 UI 改进 设计文档

日期:2026-08-11
状态:已获用户批准(方案 A:纯 QSS 美化)

## 1. 目标

改善主窗口外观(浅色简洁风格)、加大窗口尺寸、启动时定位在屏幕右侧。不改变任何功能行为与公共接口。

## 2. 方案

纯 QSS 样式表 + 窗口几何调整,零新依赖。仅修改 `main.py`,`config.py`/`transfer.py` 不动。

## 3. 具体改动

### 3.1 窗口尺寸与位置

- 主窗口:`resize(640, 560)`;配置对话框:`resize(640, 520)`
- 启动位置:主屏 `availableGeometry` 计算 —— 水平:`x = 屏宽 - 640 - 40`(右缘 40px);垂直:垂直居中 `y = (屏高 - 560) / 2`;多屏取主屏
- 位置计算抽成纯函数 `compute_window_position(screen_w, screen_h, win_w, win_h) -> tuple[int, int]`,可单元测试

### 3.2 浅色简洁 QSS(全局样式表)

- 字体:微软雅黑 10pt;标题 13pt 加粗
- 主窗口:白底
- 拖放区:圆角 12px、2px 浅蓝虚线边框(#4a90d9)、浅蓝底(#f0f6ff);dragEnter 悬停时边框变实线、背景加深(#e0eefd),松手后恢复
- 「🚀 传输」:主色蓝(#4a90d9)白字、圆角 8px、高 44px、hover 加深、disabled 灰底
- 「⚙ 配置」:白底蓝字、1px 描边次要按钮
- 虚拟机复选框与已拖列表项:字号 10.5pt、项间距 6px;已拖列表浅灰卡片底(#f7f8fa)
- 日志区:浅灰底、圆角、等宽字体(Consolas 9.5pt)
- 顶部:标题「VM Trans」+ 副标题「拖拽传文件到虚拟机」灰色小字
- 布局顺序:标题 → 虚拟机列表 → 拖放区(min 高度 150px)→ 已拖列表 → 按钮行 → 日志区(占剩余)

### 3.3 测试

- 新增 `compute_window_position` 单元测试(右缘对齐 + 垂直居中数值断言)
- 现有 6 个 main 测试保持通过
- 手动冒烟:窗口打开在屏幕右缘垂直居中、拖放高亮生效、按钮样式正常

## 4. 打包

重新运行 PyInstaller 构建 `dist/vm-trans.exe`。

- 不改任何功能逻辑、传输流程、配置格式
- 不加新依赖
- 不做深色模式/主题切换(超出本次范围)
