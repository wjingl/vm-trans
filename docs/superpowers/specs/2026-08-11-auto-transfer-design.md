# VM Trans 自动传输开关 设计文档

日期:2026-08-11
状态:已获用户批准

## 1. 目标

新增自动传输开关:UI 勾选、默认开启、状态持久化到 config.json;开启时拖入文件/文件夹立即自动传输(排队续传、传完即清)。文件与文件夹均可。

## 2. 配置

- `config.json` 顶层新增 `"auto_transfer": true`
- 新装:写入 DEFAULT_CONFIG
- 旧配置(无该字段):读取时按默认 `true` 处理,不破坏已有文件
- 勾选状态变化**立即**写入 config.json(配置记忆,无需点传输)

## 3. UI

- 按钮行最左加勾选框:「自动传输(拖入后立即传输)」
- 启动时按配置勾选;取消勾选 = 手动模式(现有行为完全不变)

## 4. 行为(排队续传 + 传完即清,已确认)

1. dropEvent 追加列表后,若自动开启**且无传输进行中** → 立即自动 start_transfer
2. 传输进行中拖入 → 新文件留列表,当前批传完后自动接着传
3. start_transfer 记录本次快照(待传项);自动模式结束后:移除快照项(列表/去重键/显示),若列表剩余非空 → 自动续传;手动模式:列表保留
4. 自动触发时日志提示「⏩ 自动传输」
5. 防重入:start_transfer 入口若 worker 运行中则忽略(自动路径保护)
6. 文件夹:复用现有递归传输,文件/文件夹一视同仁

## 5. 改动范围

- `config.py`:DEFAULT_CONFIG + 读取默认值
- `main.py`:勾选框、drop 触发、传输完成清理与续传、防重入
- 测试:配置默认/旧配置兼容/状态保存;拖入自动触发;自动完成清快照+续传;手动模式不清列表
- `transfer.py` 不动

## 6. 不做的事

- 不改传输协议与目录解析逻辑
- 不做传输队列 UI(仅列表+自动续传)
